Current Version

Version v.1.17

This update is about the table seeing what you do. Abilities, item uses and pool changes now appear in the shared log alongside rolls, the four items that cost Threat and the one that costs Momentum have real buttons, and the creator finally has a way back to the front page.

Player Changelog vs. Technical Log

This page is the player-facing changelog: it explains what changed in practical play terms. For implementation details, data schema changes, compatibility notes, and developer handoff context, use the technical notes.

Open the technical upgrade notes.

Rolls and Actions Log

The shared log in Owlbear now records abilities and item uses, not just rolls. Spend Momentum on a Counterattack and the table sees who spent it and what for.

Item Buttons

Communicator, Tactical Lens, Combat Automed and Emergency Trauma Kit have a button for their Threat cost. Combat Medkit has one for its Momentum cost.

Start Over

A Start Over button sits beside Save Local on a finished sheet, returning you to the front page without reloading the tab by hand.

Manual Changes Count

Nudging the Threat counter by hand posts to the log like anything else. Bookkeeping is visible, not secret.

Equipment First

Starting Equipment now sits above the Item Catalogue, so the list you are working from comes before the list you are searching.

Shared Roll Room Removed

The Shared Roll Room panel is gone. It needed a server that was never going to be running, so its Connect button could only ever fail.

The Rolls and Actions log is an Owlbear Rodeo feature. In a normal browser tab the creator works as it always has, with rolls and abilities shown to you alone.
Version History
v.1.17

Rolls and Actions Log, item buttons, and Start Over

  • The shared roll log became the Rolls and Actions log: it now records ability uses, item uses, and every change to the Momentum and Threat pools alongside rolls.
  • Log entries name who acted and what they used, so "Kell — Second Wind — spent 3 Momentum, regained 2 Spirit" reads as one line instead of a number moving on its own.
  • Added buttons for the five items whose rules carry a cost: Communicator, Tactical Lens, Combat Automed and Emergency Trauma Kit add Threat; Combat Medkit spends Momentum. These were previously notes asking you to move the counter yourself.
  • An item button you cannot currently afford is shown greyed out rather than hidden, so you can still see the item has the ability.
  • Manual adjustments to the Threat counter now post to the log.
  • Added a Start Over button beside Save Local on a finished sheet. It warns first if the character has not been saved locally.
  • Moved Starting Equipment above the Item Catalogue in Inventory & Equipment.
  • Removed the Shared Roll Room panel, which relied on a server that is not going to be available.
  • Confirmed that New Adventure refreshes I Know a Guy, which it already did.
v.1.16

Threat reaches the table

  • Threat changes made on the sheet now reach the shared Threat pool in Owlbear instead of only printing a reminder.
  • Roll entries in the shared log carry the real Difficulty, whether the test passed, and the Momentum gained.
  • The Owlbear character sheet and the character creator became a single page, so the sheet you play on and the sheet you build on can no longer drift apart.
v.1.15

Momentum as a group pool

  • Momentum on an Owlbear sheet is the group's pool, not a private counter. Spending it in any way — the buttons, the number field, or an ability — moves the shared total.
  • Every Threat source in the app was routed through one place, so a new one is wired into the table automatically.
